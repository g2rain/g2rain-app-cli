# 项目级架构决策

本目录记录 CLI 内部长期取舍，例如参数解析库、模板 manifest、模板 Ref 映射、临时目录/原子移动、依赖安装策略和 npm 发布保护。

影响所有生成 App 的规则提交到 g2rain 中央 `frontend-app` Profile/ADR；模板具体实现同步到 g2rain-app-template。不能只修改 CLI 让三个事实来源分叉。

## ADR 模板

```markdown
# ADR-NNNN：标题

## 状态

建议 / 已接受 / 已废弃 / 已替代

## 背景

问题、约束和当前证据。

## 决策

命令、文件系统、模板和失败语义。

## 备选方案

考虑过什么，为什么未选择。

## 影响

CLI 版本、模板兼容、生成项目、安全、测试和发布。

## 迁移与验证

实施顺序、兼容、回滚和验收。
```

ADR 不因过时删除；使用替代关系保留历史。
