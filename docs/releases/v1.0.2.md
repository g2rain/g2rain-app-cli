# create-g2rain-app v1.0.2

发布日期：2026-11-01  
对比版本：v1.0.1  
许可证：Apache-2.0

## 发布内容

本版本的 CLI 命令、参数和项目族行为保持兼容。主要变化是将 App 与 Shell 官方模板的 v1.0.2 快照纳入 npm 包，使新生成项目获得配套的宿主跳转、SSO 回跳隔离、主题和生产构建更新。

### Frontend App 模板

- 支持 `g2shell` 指定同域宿主壳；缺失或非法时使用默认宿主 Origin 与 redirect 前缀。
- 独立模式 SSO 回跳键改为 `return_url:${VITE_CONTEXT_PATH}`，隔离同域不同应用。
- production 模式裁剪 `console.log`、`console.info`、`console.debug`，保留 warn/error。
- dict Mock 的状态用途码修正为 `SUBJECT_STATUS`。

### Frontend Shell 模板

- 子应用地址统一附加 `g2shell`，Gateway 恢复前移除该宿主参数。
- SSO 回跳键改为 `return_url:${getContextPath()}`，按壳隔离。
- single-spa bootstrap/mount 超时保持 10 秒，8 秒开始告警。
- Passport 与 TenantProvision 页面采用 `--g2-*` 主题变量；production 模式裁剪 log/info/debug。
- 默认 Shell 保持 AppKit 单协议；legacy 能力继续通过 `--with-legacy` 覆盖层提供。

## 升级影响

- 该版本影响新生成项目，不会自动修改已有 App 或 Shell；已有项目按各模板 v1.0.2 Release 评估迁移。
- App 与 Shell 的 `g2shell` 约定应配套使用。壳 Context Path 应为子应用接受的单段名称。
- 旧 `return_url` 不迁移，升级过程中未完成的登录回跳需要重新发起。
- 生成 frontend-app 时，CLI 会把模板中的 `create-g2rain-app` 开发依赖改写为 `^1.0.2`。
- CLI 命令形状、默认 family、参数校验和 `--with-legacy` 语义没有破坏性变化。

## 发布验证

发布前执行：

1. `npm run verify:template-snapshots`，确认三份快照的 sourceRef 为 `v1.0.2` 且 Hash 有效。
2. `npm test`，覆盖 CLI 构建、命令分发、生成器、资源生成、身份改写和模板快照。
3. 在临时目录生成 app、默认 shell、`shell --with-legacy`，检查身份、占位符、排除项和模板来源。
4. `npm pack --dry-run`，确认 tarball 包含 dist 与三份快照，不包含 node_modules 或本地文件。
5. 发布工作流使用候选 tarball 构建三个生成项目，再通过 Trusted Publishing 发布。
