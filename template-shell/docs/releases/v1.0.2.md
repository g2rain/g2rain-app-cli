# g2rain-shell-template v1.0.2

发布日期：2026-11-01  
对比版本：v1.0.1  
许可证：Apache-2.0

## 主要变更

- 子应用 Tab 切换和 route-change 统一经 `syncBrowserAddressForTab` 更新地址栏，附加 `g2shell` 参数。值来自当前壳 Context Path 去掉首个 `/`，便于刷新和分享后返回对应宿主。例如 `/admin` 壳打开子应用后，地址可为 `/member/list?g2shell=admin`。
- `/redirect` Gateway 解析与导航目标应用前移除 `g2shell`，避免宿主选择参数进入子应用 `initialRoute`；其余 query 与 hash 保留。
- SSO 回跳记录从共享 `return_url` 改为 `return_url:${getContextPath()}`，读、写、消费和清理均按壳隔离，避免同域多个壳互相覆盖。
- single-spa bootstrap/mount 超时维持 10 秒，`dieOnTimeout=true`；warningMillis 调整为 8 秒，减少冷加载早期的 #31 警告。最终配置不是 20 秒。
- Passport、TenantProvision 页面以 `--g2-*` 变量替代固定配色，适配明暗主题。
- Vite `production` 模式使用 esbuild `pure` 配置裁剪 `console.log`、`console.info`、`console.debug` 调用，保留 warn/error；其他 mode 不启用。
- legacy 兼容文档明确以 `legacy-overlay/` 为源码来源，默认模板保持 AppKit 单协议。

## 版本与架构

模板、锁文件根版本与项目元数据统一为 `1.0.2`。中央文档统一引用 Tag `v1.0.2`；基础 Frontend App 与 Frontend Shell Profile 版本均保持 `1.0.0`。

`@g2rain/http`、`@g2rain/platform`、`@g2rain/theme`、`@g2rain/ui` 运行依赖保持 `1.0.1`。

## 升级与配套

- 与 app-template v1.0.2 的 `g2shell` 跳转规则配套：子应用识别该参数后返回当前 Origin 的 `/{g2shell}/redirect`。缺失或非法时，子应用使用默认宿主配置。旧子应用升级前需确认是否支持该参数。
- 壳 Context Path 应使用子应用可识别的单段名称（小写字母、数字、下划线、连字符，首字符为字母或数字）。嵌套 Context Path 不属于此次子应用宿主选择规则支持范围。
- 旧 `return_url` 不自动迁移；升级中未完成的登录回跳需重新发起。不同壳应使用不同 Context Path。
- 既有生成项目需评估并合并源码；CLI 内嵌 shell 模板须重新同步，并验证默认模板及 `--with-legacy` 生成结果。
- 回滚时同步恢复壳与子应用的宿主跳转约定，并检查 SSO 回跳记录；部署与密钥配置沿用[部署文档](../operations/deployment.md)。
