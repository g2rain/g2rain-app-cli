# g2rain-app-template v1.0.2

发布日期：2026-11-01  
对比版本：v1.0.1  
许可证：Apache-2.0

## 主要变更

### 集成直链返回对应宿主壳

支持查询参数 `g2shell` 指定同域宿主。例如 `/your-app/orders?g2shell=admin` 在集成意图且未被 qiankun 挂载时，转到当前 Origin 的 `/admin/redirect/your-app/orders?g2shell=admin`，参数保留给宿主壳处理。

`g2shell` 仅接受匹配 `^[a-z0-9][a-z0-9_-]*$` 的单段名称。缺失或非法时，继续使用 `VITE_MAIN_SHELL_ORIGIN` 与 `VITE_MAIN_SHELL_REDIRECT_PREFIX` 配置。跨端口开发若需要默认宿主 Origin，应移除该参数。

### 独立模式 SSO 回跳按应用隔离

登录前的页面路径改为保存到 `localStorage` 的 `return_url:${VITE_CONTEXT_PATH}`，避免同域不同 Context Path 的应用相互覆盖。认证完成、资源路由注册后读取并清除该记录，再恢复页面；没有记录时回到 `/`。

旧版 `return_url` 不自动迁移。升级时尚未完成的登录回跳需要重新发起；各应用应使用不同的 Context Path。

### 生产日志与 Mock

- Vite `production` 模式通过 esbuild `pure` 配置裁剪 `console.log`、`console.info`、`console.debug` 调用；保留 `console.warn`、`console.error`，其他 mode 不启用此配置。
- dict Mock 中 ACTIVE、INACTIVE 的 `usageCode` 从 `MEMBER_STATUS` 修正为 `SUBJECT_STATUS`。

### 文档与版本

- 模板版本、锁文件根版本及项目元数据统一为 `1.0.2`。
- README 修正 Auth Bridge 认证、实例身份及 HTTP/UI 目录职责说明；Token 不经公开 props 传递。
- 中央文档统一引用仓库 Tag `v1.0.2`；Frontend App Profile 版本保持 `1.0.0`。
- `@g2rain/http`、`@g2rain/platform`、`@g2rain/theme`、`@g2rain/ui` 运行依赖保持 `1.0.1`。

## 升级与交付

已有应用需按上述变更评估并合并源码，更新文档不会自动升级已生成项目。保持宿主壳与子应用对 `g2shell` 参数处理一致，并验证默认宿主兜底路径。

CLI 维护者需同步内嵌模板，并验证生成项目的版本、占位符替换与构建。模板仍通过 `file:../g2rain-app-cli` 使用同级 CLI；本地安装和生成命令的环境要求见[本地开发](../development/local-development.md)。

## 验证结果与已知限制

- `npm run build` 通过，包含 TypeScript 类型检查及 Vite 生产构建。
- 文档相对链接、版本一致性与 Git Diff 格式检查通过。
- 构建仍有 MockJS `eval`、chunk 体积、动态导入与 `env-config.js` 提示，详见[架构偏差](../architecture/deviations.md)。
- 浏览器独立/集成模式、多实例、SSO、宿主壳及容器联调未验证；构建通过不代表这些流程已验收。
