# 项目级架构决策

本目录记录只影响 g2rain-app-template 或前端模板演进的长期取舍，例如：

- qiankun 多 Tab 实例隔离方案。
- 运行时配置注入方式。
- 页面/权限资源生成格式。
- components、platform、runtime 边界迁移。
- 模板升级对生成项目的兼容策略。

影响多个 g2rain 前端 App 并需要组织强制执行的决策，应在本项目验证后提交到 g2rain 中央仓库，更新 `frontend-app` Profile 或增加组织级 ADR；不能只修改本地规范静默覆盖中央基线。

## ADR 模板

```markdown
# ADR-NNNN：标题

## 状态

建议 / 已接受 / 已废弃 / 已替代

## 背景

问题、约束和证据。

## 决策

选择的方案和明确规则。

## 备选方案

考虑过什么，为什么未选择。

## 影响

对模板、新生成项目、已有项目、配置、安全和测试的影响。

## 迁移与验证

实施顺序、兼容、回滚和验收方式。
```

ADR 不因过时直接删除；使用新 ADR 标记替代关系并保留历史。
